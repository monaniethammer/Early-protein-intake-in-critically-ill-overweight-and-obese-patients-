# Code/Preprocessing 📂

Dieser Ordner enthält alle relevanten Codes für die Datenaufbereitung. Für Reproduktion: Es muss zuerst preproc-data.R, dann calc-metrics.R ausgeführt werden.

- `preproc-data.R` – Preprocessing-Skript von Andreas Bender, welches bereits auch in früheren Projekten verwendet wurde.  
  > ⚠️ Dieser Code ist nur zum Nachvollziehen hinterlegt, er läuft nicht durch, da er bereits vorab ausgeführt worden war und nicht weiter verwendet oder geändert wurde. Auf das Hinzufügen sämtlicher Rohdaten wurde daher hierfür verzichtet.
- `preproc-helpers.R` – Hilfsfunktionen für preproc_data.R
- `calc-metrics.R` – Projektspezifische Datenaufbereitung, insbesondere Zensierung und Berechnung von avDPI & avDCI sowie Filtern auf übergewichtige Pagtient:innen
