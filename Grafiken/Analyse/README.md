# Grafiken/Analyse 📂

- Dieser Ordner enthält Grafiken, die aus den Hauptanalysen (z. B. Cox-Modellen, Kaplan–Meier-Plots oder Konturplots) generiert wurden. 
- Sie dienen der Darstellung der Überlebensanalysen, der Übergangswahrscheinlichkeiten (Contour Plots) sowie der Hazard-Raten (z. B. Hazard-Ratio-Plots) und bilden die Grundlage für die Interpretation der Hauptergebnisse.
